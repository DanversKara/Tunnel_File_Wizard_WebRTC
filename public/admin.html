Access control

The master switches. Changes apply immediately.

Login required
When ON, only signed-in users can send or receive files — anonymous strangers are locked out entirely. This is the anti-abuse switch: flip it on if bad actors find your server. When OFF, anyone with the link can use it (the original behavior).
Sign-up mode
Only matters when login is required. Invite only: new users need a code you create below. Public: anyone can create an account.
Site address
Used in the links inside emails. Should be the public URL of this server.

Users

Everyone with an account. Disabled users are signed out immediately and can't sign back in.
